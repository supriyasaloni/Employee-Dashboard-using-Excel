# Employee-Dashboard-using-Excel

📊 Employee Performance Dashboard (Excel)
Project Overview

This project is an Employee Performance Dashboard created in Microsoft Excel to analyze employee productivity and performance. The dashboard provides key insights such as working hours, efficiency, active customer time, breaks, and overall performance in an interactive format.

Features
Employee Working Hours Analysis
Efficiency Tracking
Overall Performance Summary
Break Time Analysis
Interactive Dashboard
Easy-to-read charts and KPI cards
Excel Features Used
Pivot Tables
Pivot Charts
Slicers
Conditional Formatting
Excel Formulas (SUM, AVERAGE, IF, etc.)
Data Cleaning
Dashboard Design & Formatting
Tools Used
Microsoft Excel
Pivot Table
Pivot Chart
Slicers
Conditional Formatting
Dashboard Insights
Compare employee working hours.
Monitor employee efficiency.
Track active customer handling time.
Analyze break duration.
Identify top and low performers.
